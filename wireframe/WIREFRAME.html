Smart Note Taker - Wireframe

This file works on its own - all images are embedded inside it. No other files needed.

Goal: show page structure, navigation, major sections, forms, buttons, cards, and user flow - before coding.

Corrected overview - use this one

Matches the built app exactly: Landing, Dashboard, Notes view, Upload, Login/Register, Profile. No Revision or Saved page - those are not in the MVP.

User flow

Landing (/) -> Register / Login -> Dashboard (/dashboard)
  -> Upload (/upload) -> Processing (1.5s, simulated) -> Dashboard (new note on top)
  -> Note Detail (/notes/[id]) -> Favourite / Delete -> Dashboard
  -> Profile (/profile) -> notes table

Landing - /

Navbar: Logo | Home | Dashboard | Upload | Login. Hero: "Stop missing the next point", buttons [Get started free] [See my notes]. Features: 4 cards - Upload, Short summary, Key points, Search.

Dashboard - /dashboard

Stats row, search + subject filter, cards grid with subject/status badges, Empty State when no match.

Note Detail - /notes/[id]

Summary card, key points (highlighted), transcript excerpt, Favourite / Delete (with confirm Modal).

Login / Register - /login, /register

Centred card form: Email + Password (login); Full name + Email + Password (register). On success: redirect to /dashboard.

Upload - /upload

Form: Lecture title, Subject, Lecturer, Duration, Recording file name, Transcript. Button [Generate my notes], 1.5s loading, then Dashboard.

Profile - /profile

User card, stats, table of all notes (Title / Subject / Date / Status).
